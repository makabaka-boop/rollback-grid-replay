# 完全本地运行的双人 12×12 格点回放器

这是一个无外部依赖、无网络请求、无需构建的静态网页。重放计算运行在 Web Worker 中；主线程只负责把日志送入 Worker，并播放、单步、跳转或导出 Worker 返回的同一份逐 tick 结果。

## 运行

直接用现代浏览器打开 `index.html` 即可。若浏览器对 `file://` 有限制，也可以在本目录启动一个仅本地的静态服务：

```bash
python3 -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

运行测试：

```bash
npm test
# 或
node --test replay-core.test.js
```

## 指令格式

日志最长 300 tick。文本格式为每行一个 tick：

```text
tick A指令 B指令
```

显式 tick 可以乱序；省略 tick 时从上一条显式 tick 后顺延。例如：

```text
0 right up
1 stay left
20 down right
```

支持的指令：

- `up` / `u` / `上`
- `down` / `d` / `下`
- `left` / `l` / `左`
- `right` / `r` / `右`
- `stay` / `s` / `.` / `停`

也支持 JSON：

```json
[
  ["right", "up"],
  { "a": "stay", "b": "left" },
  null,
  ["down", "right"]
]
```

`null` 或缺失 tick 均表示双方停留。对象形式还支持：

```json
{ "20": { "a": "down", "b": "right" } }
```

## 裁决规则

每个整数 tick 读取两名角色的同一组指令，并一次性计算结果，和两条指令在输入对象中的键顺序无关：

1. 指令使角色越过 12×12 边界时判为撞墙，意图位置回退到原格，本 tick 不移动。
2. 双方移动后的目标格相同：产生 `COLLISION_SAME_CELL`，双方均停在原格。
3. 双方互相穿过（A 到 B 原格且 B 到 A 原格）：产生 `SWAP_POSITIONS`，交换被阻止，双方均停在原格。
4. 同格相遇或交换时不吃拾取物、不加分。
5. 正常移动后若到达未拾取的一次性道具格，立即加分并永久移除该道具。

逐 tick 摘要包含：双方坐标、指令、意图坐标、撞墙标记、碰撞类型、是否移动、拾取结果、分数、事件列表和已拾取道具。

## 检查点与补录

- tick 0 保存初始检查点。
- 每 10 tick 保存一个检查点（10、20、30、…）。
- “追补/改动”发送稀疏日志。Worker 找到最早变更 tick `t`，使用：

  ```text
  floor(t / 10) * 10
  ```

  处最近且不受影响的检查点，然后重新生成该检查点之后的全部命令和逐 tick 摘要。
- 修改 tick 0 或缺少可用检查点时进行完整重放。
- “完整载入并重放”忽略增量关系，总是从 tick 0 重新生成全部结果。
- “所选按批次追加；无选择则完整载入”在选中一段文本时，把这段连续指令追加到当前日志末尾；没有选区时会用全文完整重放。

Worker 返回结果带代次号；主线程只接受最新代次，旧代次完成后会被丢弃，不能覆盖新日志。播放、单步、跳转和导出都读取当前 `activeReplay`，导出的是完整重放结果而不是当前画面。

## 文件

- `index.html`：本地界面与 Worker 装配。
- `replay-core.js`：纯函数重放核心，浏览器 Worker 和 Node 测试共用。
- `replay-core.test.js`：确定性、碰撞/拾取、300 tick 限制、10 tick 检查点、分批送达、乱序追补和与从头完整重放的逐状态比较。
